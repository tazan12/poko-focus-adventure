# 포코와 별빛 탐험대 — ADHD 아동 집중력 훈련 게임 기획서

작성일: 2026-09-15
대상: 만 7–12세 ADHD 아동 (보호자 동반 사용 권장)
플랫폼: 웹 브라우저 (PC / 태블릿, 키보드·터치 모두 지원)
목적: 억제조절(inhibitory control), 지속주의(sustained attention), 작업기억(working memory), 간섭통제(interference control)를 짧고 즉각적인 보상 구조 안에서 반복 훈련

> 이 게임은 의료기기가 아니며 진단·치료를 대체하지 않습니다. 약물·행동치료의 **보조 훈련 도구**로 설계되었습니다.

## 2. 게임 컨셉

**세계관**: 별빛이 사라진 숲을 탐험하는 여우 탐험가 **포코**와 함께, 아이가 "집중의 힘"으로 별을 되찾는 모험.
**동반자 캐릭터 포코 (Higgsfield 생성)**: 4가지 상태 — 기본 / 환호(정답 연속) / 격려(오답 시, 절대 비난하지 않음) / 집중(미션 시작 전 안내)
**자극 캐릭터**: 별별이(Go 대상, 노란 별) / 심술이(No-Go 대상, 보라 가시)

### ADHD 맞춤 설계 원칙
1. **즉각 보상**: 정답 즉시(<100ms) 시각·청각 피드백 — ADHD의 지연 혐오(delay aversion) 고려
2. **짧은 블록**: 미션 1개 = 60–90초. 블록 사이 포코의 격려 화면
3. **오답에 비처벌적**: 감점 대신 "다음엔 잡을 수 있어!" — 좌절감(AKL-T01 부작용 3%) 최소화
4. **적응형 난이도**: 20시행마다 정확도 평가 → ≥85% 1단계 상승, <65% 1단계 하강, 그 외 유지 (급변 금지)
5. **시각적 절제**: 미션 화면은 자극 외 움직이는 요소 최소화(주의 분산 방지), 파스텔 저채도 배경
6. **세션 상한**: 하루 25분 도달 시 종료 안내(과몰입 방지)

## 3. 미션(모듈) 구성 — "과제 구조는 그대로, 껍데기는 게임으로"

EndeavorRx(AKL-T01)가 표준 인지과제를 우주선 레이싱으로 감싼 것과 같은 원리. 자극 비율·제시 시간·ISI 등 측정에 영향을 주는 파라미터는 원형 과제와 동일하게 유지하고, 시각적 맥락·캐릭터 반응·콤보 보상만 덧입혔다.

| 미션 (세계) | 훈련 영역 | 과제 원형 | 게임 껍데기 | 핵심 파라미터 (근거) |
|------|----------|----------|------|----------------------|
| ① 반짝 숲 달리기 | 억제조절, 충동성 | Go/No-Go | 포코가 숲길을 달리고, 덤불에서 튀어나온 별별이를 점프해서 잡음. 심술이는 참고 지나감. 잘 참으면 "잘 참았어!" 조용한 보상 | Go 80% / No-Go 20%, 자극 500ms, ISI 1500ms → 레벨↑ 시 자극 400/350ms, ISI 1200/1000ms. 레벨 5+에서 "마법의 안개"로 규칙 반전(유연성) |
| ② 별자리 망원경 | 지속주의, 경계 | CPT | 망원경 시야에 친구들이 반짝임. 별별이를 잡을 때마다 별자리에 별이 켜지고 선이 이어짐(누적 진행 가시화) | 표적 확률 18~30%, 75~110초 지속, RT SD·후반 누락 증가(경계 저하) 기록 |
| ③ 반딧불 연못 | 시공간 작업기억 | N-back (3×3) | 연잎 위에 반딧불이 앉음. n번 전과 같은 연잎이면 포코가 폴짝 뛰어 반딧불 획득(물결 효과) | 1-back 시작, 3000ms 간격, 20시행, 정확도 80%↑ 승급 |
| ⑤ 강물 길잡이 | 선택주의, 간섭통제 | Flanker (Eriksen) | 5마리 물고기 중 가운데 길잡이가 가리키는 쪽으로 노 젓기(← → / 좌우 터치). 맞으면 보트가 그쪽으로 미끄러지며 물보라 | 불일치 40→70%, 응답 2.5→1.2초. 지표: 플랭커 효과(불일치 RT − 일치 RT). 근거: Krauel 2025 JAMA Netw Open(소아 ADHD RCT 표적 과제) |
| ⑥ 숨은 별별이 찾기 | 선택주의(시각 탐색) | Visual search | 동굴 속 6~24개 자극 중 별별이 1개를 터치. 레벨↑: 세트 크기↑·제한시간↓·심술이(오터치 함정)·자극 이동 | 지표: 탐색 RT, 오터치, 못 찾음 |
| ⑦ 마법 보물 분류 | 인지 유연성(규칙 전환) | DCCS/과제전환 | 보석을 "색깔로"/"모양으로" 규칙에 따라 좌우 상자에 분류. 레벨↑: 전환 블록 10→4→무작위, 제한시간↓ | 지표: 전환 직후 정확도, 전환 비용(RT), 고집 오류. 근거: Tramoni 2026(유연성 개선) |
| ④ 마법 물약 공방 | 간섭통제, 유연성 | Stroop | 주문서 글자의 '색'과 같은 물약을 골라 솥에 넣으면 물약 완성(솥 색 변화+거품) | 일치/불일치 60:40→30:70, 응답 3.0→1.2초 제한 |

### 뇌게임 벤치마킹 미션 (⑧~⑪) — 메커니즘만 재구성, 이름·그림·UI는 독자 제작
| 벤치마크 메커니즘 | 우리 미션 | 훈련 영역 | 핵심 규칙 |
|---|---|---|---|
| 숫자 잇기(Trail Making·Connect형) | ⑧ 별 잇기 (등불 정원) | 처리속도·주의 전환 | 1→N 순서 터치. 스테이지 6+ 숫자↔ㄱㄴㄷ 번갈아(TMT-B형). 지표: 등불당 시간·순서 실수 |
| 드나드는 인원 세기(Head Count형) | ⑨ 텐트 친구 세기 (별빛 캠프) | 작업기억 갱신 | 친구가 텐트에 들어가고 나온 뒤 안의 수를 답함. 스테이지↑ 이동↑·속도↑·시작 인원 숨김 |
| 낮은 수부터 터뜨리기(Low-to-High형) | ⑩ 풍선 순서 기억 (축제 광장) | 기억 폭 | 숫자 풍선을 잠깐 보고 가려지면 작은 수부터. 풍선 3→7개 |
| 빠른 계산(Calculations형) | ⑪ 열매 계산 (별빛 과수원) | 처리속도 | 덧셈·뺄셈(·곱셈) 3지선다. 수 범위 10→100 |
| 소리 순서 따라하기(Simon/Sound Bites형) | ⑫ 별빛 멜로디 (음악 마을) | 시청각 순서 기억 | 종 4개(7+ 5개)가 순서대로 빛나며 음을 냄 → 같은 순서로 터치. 성공 시 1음씩 길어짐(2→9). 지표: 최고 기억 길이(span) |

하루 세션 = 핵심 4개(①②③④) + 날짜별 로테이션 3개(⑤~⑫ 중) = 7개 미션, 약 12분. 총 12세계.

### 세계별·단계별 음악
`js/music.js`: 세계마다 조성(C·F·D·A·G·E·B♭·…)·선법(장조·펜타토닉·리디안·도리안)·템포(78~116 BPM)·음색이 다른 64스텝 루프. 스테이지 구간별 편곡: 1~3 기본 / 4~6 아르페지오·하이햇 / 7~9 템포 +10, 킥, 후반 옥타브↑ / 10 단조 변환·템포 +18·8분 베이스(보스).

### 보호자 리포트 인포그래픽
요약 타일(훈련일·미션·시간·별·연속 출석) → 힘 지도(11축 레이더, 세계별 최근 3회 평균) → 최근 4주 히트맵(일별 놀이 시간, 단일 색조 5단계) → 세계별 카드(정확도 추세선 + 75% 가이드, 처음 3회 대비 변화 ▲▼, 스테이지 별 띠, 핵심 지표). 단일 계열·단일 색조 원칙, 텍스트는 잉크색, 호버 툴팁 제공.

### 화면 용어 원칙
게임 화면(UI)에는 ADHD·부주의·충동성·진단·임상 같은 표현을 쓰지 않는다. 미션 영역은 "참는 힘·지켜보는 힘·기억하는 힘·찾는 힘·고르는 힘·바꾸는 힘·속지 않는 힘"으로, 리포트 지표는 "놓친 별별이·심술이 건드림·반응 들쭉날쭉" 등 놀이 언어로 표기한다. 임상 근거와 원 지표명(omission/commission/RT SD 등)은 이 문서와 JSON 내보내기의 필드명에만 남는다.

### 스테이지 변주 시스템 — "같은 과제, 다른 스테이지"
10스테이지가 같은 패턴이면 아동은 3스테이지쯤에서 흥미를 잃는다. 그러나 자극 비율·제시 시간·ISI를 스테이지마다 바꾸면 측정 코어가 흔들린다. 따라서 변주는 **보상층·시각층·시행 사이(inter-trial)**에만 두고 스테이지마다 하나씩 누적 해금한다(`js/stagefx.js`).

이벤트는 각 과제 루프의 `await ctx.between()`(시행 종료 후, 다음 자극 제시 전)에서만 실행되므로 RT·누락·오경보 측정에 영향이 없다. 세계별 변주로 별자리 망원경은 스테이지마다 별자리 모양(물결·여우·배·왕관·하트)이 바뀐다.

### 티어별 규칙 변화 (기존 7개 세계)
스테이지 변주(보상·시각층)만으로는 "같은 과제 반복" 느낌이 남아, 과제 자체에도 3개 티어(1–3 / 4–6 / 7–10)마다 눈에 보이는 규칙 변화를 두었다. 변화는 결과 metrics에 기록된다(spots/fog/burst/colors/flash/flankers 등).

| 세계 | 4–6 | 7–10 |
|---|---|---|
| 반짝 숲 (Go/No-Go) | 3+ 토끼 합류(Go 자극 2종), 5+ 규칙 반전 | 6+ 안개(가까이 와야 또렷), 7+ 부엉이(숙이기 = 두 번째 반응), 8+ 가속 구간(가운데 블록 응답창 70%) |
| 별자리 망원경 (CPT) | 자극 위치가 하늘 전체로 확대 | 자극이 좌우로 떠다니며 지나감 |
| 반딧불 연못 (N-back) | 2-back | 3-back + 반딧불 색 무작위(무관 차원 간섭) |
| 마법 물약 공방 (Stroop) | 주문서 0.9초 후 사라짐(제한시간 유지) | 보라 추가 5색 |
| 강물 길잡이 (Flanker) | 물고기 5→7마리 | 물고기 떼 흔들림·이동 |
| 숨은 별별이 (탐색) | 심술이 함정 | 6+ 드리프트, 8+ 가짜 별별이(채도 낮은 별) |
| 마법 보물 분류 (전환) | 전환 블록 단축 | 규칙 두루마리 1.2초 후 흐려짐(규칙 유지 기억) |

### 반짝 숲 v2 — "다가오는" 러너 (테스터 피드백 반영, 2026-09-15)
테스터 의견: "덤불에서 튀어나오는" 방식은 어디를 볼지 몰라 반응이 늦고, "그냥 지나치라"는 글 설명보다 캐릭터가 직접 스쳐 가는 모션이 필요하다는 것. 그래서 자극이 **오른쪽에서 한 명씩 포코를 향해 달려오는** 구조로 바꿨다.
- 응답 창 = 친구가 포코 앞에 도착할 때까지의 시간(= 기존 stim + ISI, 레벨별 2150→1100ms). 이동 거리와 포코 위치로 도착 비율(passFrac)을 계산해 애니메이션 길이를 정한다. Go:No-Go 80:20, 20시행 블록, 후반 반전은 그대로.
- 별별이·토끼(Go) → 점프하면 포코 품으로 빨려 들어와 터짐. 응답 창 45% 이내면 "번개 판단" +1 (멀리 있을 때 바로 판단하도록 유도).
- 심술이(No-Go) → 아무것도 누르지 않으면 혀를 내밀고 폴짝 뛰어 옆으로 스쳐 지나가고 포코가 몸을 젖힌다("휙~ 잘 참았어!"). 누르면 부딪혀 튕겨남(commission).
- 부엉이(7+, Go의 1/4) → 머리 높이로 날아와 **숙이기**(↓/버튼)로 피한다. 점프하면 wrong(선택 오류), 무반응은 omission. 지표에 `wrong` 추가.
- 놓친 Go 자극은 지나가며 날아올라 사라진다(omission, 부드러운 피드백).
- 점프 시트: 팔을 치켜든 프레임이 "팔이 남아 있는" 것처럼 보인다는 피드백 → 앞발을 몸에 붙인 6프레임 시트로 재생성(`poko_jump`).

### 반짝 숲 v3 — 잡기와 피하기의 구분 (2026-09-15)

### 나이 곡선 — 청소년·어른·어르신 (2026-09-16 개정)
"어른"을 고르면 25살로 고정되던 것을 없애고, 14살 이상은 **실제 나이를 직접 입력**한다(14~99). 시간 창 배율은 나이별 꺾은선 보간 `Adaptive.AGE_CURVE`: 6살 1.20 → 8살 1.10 → 10살 1.00 → 13살 0.90 → 17살 0.80 → **22살 0.75(최고 속도)** → 40살 0.78 → 55살 0.88 → 65살 1.00 → 75살 1.15 → 90살 1.30. 처리 속도가 20대에 정점을 찍고 완만히 감소한다는 연령 곡선(Salthouse 2010)을 따른 것으로, 어르신은 어린이 수준의 여유를 돌려받는다.
- **65살+ (`Adaptive.senior`)**: 하트 5개, 스테이지 1부터(빠른 시작 없음), 하루 30분 권장, 열매 계산은 100 이내 덧셈·뺄셈+구구단(75살+는 50 이내). 스피드 도전은 원하면 여전히 켤 수 있다.
- 14~64살(`grown`): 스테이지 1~3 열림·레벨 3 시작·45분·스피드 도전.
- **나이 프라이버시**: 정확한 나이는 본인 기기와 서버(난이도·밴드 계산용)에만 있고, 홈 칩·랭킹·친구 목록 등 다른 사람이 볼 수 있는 곳에는 연령대만 표시한다(`Online.ageBand`). 서버 `poko_rank`도 `band`만 내보낸다. 본인은 탐험대원 카드에서 언제든 정확한 나이를 보고 무료로 고칠 수 있다.
- 랭킹 나이대: 6~8 / 9~10 / 11~13 / 14~17 / 18~29 / 30~49 / 50~64 / 65~74 / 75살+ (서버 `poko_age_band` 동일). 이미 "어른(25)"로 등록한 이용자는 탐험대원 카드에서 나이를 무료로 고칠 수 있다.

### 캐릭터 표정·제스처
정적 표정 10종(기본·환호·격려·집중·놀람·생각·졸림·뿌듯·시무룩·신남) + 애니메이션 5종(달리기·점프·대기·춤·손흔들기). 오경보엔 놀람, 누락엔 격려, 5콤보엔 뿌듯, 10콤보엔 신남, 황금 별별이엔 놀람, 인트로에선 손 흔들기, 별 3개엔 춤, 25분 소진 시 졸림 — 처벌적 표정(시무룩)은 사용하지 않는다.

### 다양화 요소 (닌텐도식 변주)
- **황금 별별이**: 숲(Go 시행의 6%)·망원경(표적의 8%)에 희귀 등장. 잡으면 +5 코인·특별 효과음. 측정상으로는 동일한 Go/표적 시행이라 과제 구조를 해치지 않음
- **오늘의 도전**: 날짜별로 하나 정해지는 보너스 목표(예: "심술이 한 번도 안 건드리기", "8연속 콤보", "별자리 80%"). 세션 완료 시 평가, 달성 시 +25~50 코인. 같은 과제를 매일 다른 목표로 플레이하게 함
- **입력 다양화**: 누르기/참기(①②③), 4지선다(④), 좌우 방향(⑤)으로 조작 방식이 바뀜
- **세계 선택 카드**: 5개 세계를 카드 캐러셀로, 획득 스티커·레벨 표시

### 게임 껍데기 공통 요소
- **콤보**: 연속 정답 5회마다 코인 배율 ×2, ×3 (최대). 오답 시 리셋. 즉각 보상 빈도를 높여 지연 혐오를 보완
- **포코 실시간 반응**: HUD의 포코가 3연속 정답에 환호, 오답에 격려 표정으로 바뀜(비난 없음)
- **즉시 피드백**: 응답 순간에 애니메이션·효과음·코인 날아가기(<100ms). 누락은 "별이 지나갔어…" 같은 부드러운 문구
- **수집**: 미션에서 별 2개 이상이면 세계별 스티커 획득(홈 화면 표시). 세션 종료 시 별 지도에서 클리어한 세계가 밝아짐
- **캐릭터 애니메이션**: Higgsfield로 생성한 스프라이트 시트(달리기 6프레임 12fps, 점프 6프레임 14fps, 대기 4프레임 4fps, 별별이/심술이 4프레임 6fps)를 JS 프레임 재생기로 구동. 시트는 한 줄이 아니라 3×2/2×2 격자로 요청해야 이웃 프레임의 꼬리가 겹치지 않는다(한 줄 6칸은 꼬리가 잘림). 점프는 바닥 정렬 프레임에 코드로 포물선(translateY)을 입힌다
- **일시정지/그만하기**: 모든 대기 타이머를 추적해 남은 시간을 보존한 채 정지(측정 타이밍 왜곡 없음). 정지 시간은 훈련 시간에서 제외. 그만하기 시 해당 미션은 기록하지 않음(불완전 데이터 배제)
- **주의 분산 억제**: 자극 영역 밖의 지속 움직임은 숲길 배경 스크롤(저대비)과 포코 달리기 하나로 제한. 파티클·팝업은 0.6초 이내 소멸

### 세션 흐름 (약 20분)
1. 포코 인사 + 오늘의 목표 (30초)
2. 미션 ① (2분) → 보상 → 미션 ③ (2분) → 보상 → 미션 ② (2분) → 보상 → 미션 ④ (2분)
3. 별 지도에 별 채우기(진행도) + 보호자용 요약

### 하트(목숨)와 미션 중단 — "무조건 완주"가 아니다 (2026-09-16)
- 미션마다 하트가 있다: 6~8살 5개, 9~13살 4개, 14살+ 3개. **실수(부딪힘·오답·오경보)** 마다 1개씩 줄고, 놓침(soft: 별 놓침·시간 초과)은 깎지 않는다. 별빛 보호막 아이템이 막으면 유지. 하트 1개 남으면 경고.
- 0이 되면 `FailError`로 미션의 모든 대기가 끊기고 **실패 화면**(`screen-fail`)으로 간다: 그 미션 코인은 절반만, 별·스티커·목표 보너스 없음, 세션 적응 레벨은 1단계 하강, 기록에 `failed:true`(리포트 지표 집계에서 제외, "중단 n회" 표시). "다시 도전" / "스테이지 지도로".
- 근거 측면: 실패 종료는 과제 시행 수를 줄이지만, 아이가 무의미하게 눌러대며 완주하는 것보다 억제 조절 동기가 생긴다. 테스트 봇은 `localStorage.poko_debug_lives=99`.

### 반짝 숲 — 점프·숙이기 타이밍 (2026-09-16)
- 통나무·꿀벌은 응답 창의 마지막 45%(`ZONE=0.55`)가 "구간": 장애물이 반짝이며 **"지금!"** 이 뜬다. 이 구간에서 누르면 성공(점프 포물선이 장애물 통과와 겹친다).
- 너무 일찍 뛰면 동작은 나가지만 결과는 도착 시점에 `early`로 판정 → **넘어지는 동작**(`.runner-poko.trip`, 회전해 엎어짐) + 하트 -1. 안 누르면 통나무는 넘어짐, 꿀벌은 부딪힘. `early`는 지표에서 `wrong`으로 집계.
- 잡기(별별이·친구)도 타이밍 동작(2026-09-16 요청): "지금!" 구간에서만 성공, 너무 일찍 뻗으면 헛손질(별별이가 지나가 버림) + 하트 -1. 코앞(마지막 20%)에서 잡으면 "딱 맞춰 잡았다!" +1. 반응 시간은 여전히 등장 시점부터 기록하되, 이제 "판단 속도"보다 "타이밍 정확도"에 가깝다.
- **점프 장면 동기화**: 구간 안에서 누르면 점프 길이를 `2×도착까지 남은 시간`(480~1100ms)으로 잡아 **정점에서 통나무가 발밑을 지나게** 하고, 착지 때 먼지·찌그러짐(`.land`)을 넣는다. 숙이기는 꿀벌이 지나갈 때까지(`도착+380ms`) 납작하게 유지. 칭찬 팝업은 누른 순간이 아니라 실제로 넘는 순간에 뜬다.

### 모자를 써도 계속 움직인다 (2026-09-16)
정지 그림으로 바꾼 것은 "최악"이라는 피드백 → **주인공×모자 착용 서기 애니메이션 시트** 48장(`sprites/{hero}_idle_hat_{hat}.png`, 4프레임 숨쉬기·눈깜빡임)을 생성. 캐릭터당 3행×4열 시트 2장(행=모자, 열=프레임)으로 만들어 16장 생성 + 배경 제거 → `dl_hatidle.py`가 행별로 잘라 시트화. `Sprite.hat`이 설정되면 `resolve()`가 idle/wave/dance/jump 요청을 착용 서기 시트로 해석하고(점프는 arc로 폴짝, 춤은 arc 12 바운스), 홈·상점·안내·보상·종료가 모두 스프라이트 재생으로 돌아갔다. 정적 `showStatic`은 더 이상 쓰지 않는다. 미션 중 달리기에는 여전히 모자 없음.

### BGM v2 — 세계별 음원 파일 (2026-09-16)
합성 시퀀서 대신 **Higgsfield `sonilo_music`(텍스트→음악)** 으로 만든 곡을 쓴다: 홈 1곡 + 세계 12곡, 각 60초 루프, 프롬프트는 세계 분위기(숲=우쿨렐레·박수 112BPM, 연못=오르골 84, 망원경=첼레스타 76, 동굴=피치카토 100, 강=하프·플루트 96, 다락=실로폰·아코디언 104, 물약=벨·클라리넷 100, 정원=칼림바 92, 캠프=기타·하모니카 90, 광장=장난감 트럼펫 110, 과수원=밴조·휘파람 108, 무대=피아노·차임 88, 종소리 효과음과 겹치지 않게 성김). `tools/build_music.py`가 96kbps mp3·-18 LUFS·페이드로 변환(`assets/music/*.mp3`, 곡당 약 0.7MB). `js/music.js`의 `Music`이 두 `<audio>`를 교차 페이드하며 재생하고, 스테이지 구간(4~6/7~9/10)은 재생 속도 1.04/1.08/1.12(음높이 유지)로 긴장감을 준다. 파일 로드 실패 시 기존 시퀀서(`SynthMusic`)로 자동 대체. 볼륨은 홈 0.45 / 미션 0.32, 일시정지 시 0.35배.

### 휴대폰·태블릿 인터페이스 점검 (2026-09-16)
`scratchpad/audit_devices.js`로 폰 세로(390×844)·폰 가로(844×390)·태블릿 세로(820×1180)에서 홈·상점·카드·세계·지도·안내·12미션·일시정지·랭킹·리포트를 캡처해 점검. 수정: (1) HUD 미션명 한 줄 말줄임, 하트 줄바꿈 금지·최대 8개 표시, (2) 별빛 멜로디 종 폭 15vw·간격 축소(가로 넘침), 열매 줄바꿈 금지, (3) 별 잇기 등불 좌표를 9~91%/10~90%로 제한(화면 밖 잘림), (4) `html,body overflow-x:hidden`·`#screen-task overflow:hidden`(팝업 등 일시 가로 스크롤 차단), (5) 가로 폰(높이≤520): 홈·세계 고르기 스크롤 허용, 안내 카드는 스크롤 + "준비됐어!" 버튼 sticky 고정, (6) 태블릿 세로(601~1024): 세계 카드 3열·캐릭터 4열·러너 캐릭터 24%·버튼 확대, (7) 러너·연못 캐릭터 크기를 JS 분기 대신 CSS 변수(`--char-h`)로 기기별 제어, 달려오는 상대의 폭은 DOM 실측으로 도착 시점 계산.

### 업데이트 반영 (서비스워커)
앱 셸(HTML/JS/CSS/JSON)은 **네트워크 우선**, 에셋은 캐시 우선. 새 서비스워커가 자리 잡으면(`controllerchange`) 미션 중이 아닐 때 한 번 자동 새로고침 → 새 배포가 첫 접속에 바로 보인다(이전에는 캐시 우선이라 두 번 열어야 반영).

## 5. 기술 스택
- 순수 HTML/CSS/JavaScript (의존성 없음, 오프라인 실행 가능)
- Web Audio API로 효과음·BGM 합성(외부 파일 불필요). BGM은 홈(84 BPM, 잔잔함)·미션(104 BPM, 낮은 볼륨) 두 테마, 켜기/끄기 토글 제공 — 배경음악이 주의를 분산시킬 수 있는 아동을 위해 기본 볼륨을 낮게 두고 보호자가 끌 수 있게 함
- 캐릭터·배경·스티커 에셋: Higgsfield `gpt_image_2_5` 생성 (캐릭터/스티커는 transparent background PNG, 배경은 JPG). 새 친구: 토끼·다람쥐·부엉이(별자리 망원경 4+, 숨은 별별이 3+, 별 세기 풀에 합류). 스프라이트: poko_run/jump/idle/dance/wave/duck, star_idle, spiky_idle/run
- 온라인(선택): Supabase REST RPC (`js/online.js`). 없으면 완전 오프라인으로 동작
- 참고 코드: 위 GitHub 저장소 (MIT)
