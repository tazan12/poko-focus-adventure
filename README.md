# 포코와 별빛 탐험대 — 아동 집중력 훈련 게임

근거 기반으로 설계한 웹 브라우저용 집중력 훈련 게임입니다. (개발 문서에는 ADHD 관련 근거를 기록하지만, 게임 화면에는 해당 용어가 나타나지 않습니다.) 캐릭터는 Higgsfield(GPT Image 2.5)로 생성했습니다.

## 바로 플레이 / 설치
- **공개 주소(휴대폰·PC)**: https://tazan12.github.io/poko-focus-adventure/ — Android는 홈 화면의 "📲 앱으로 설치", iPhone은 Safari 공유 → "홈 화면에 추가". 한 번 열면 오프라인에서도 실행됩니다.
- 저장소: https://github.com/tazan12/poko-focus-adventure
- 로컬: `game/index.html` 더블클릭, 또는 `cd game && python -m http.server 8000`

## 온라인 기능 (탐험대원 카드 · 친구 초대 · 주간 랭킹)
- 홈의 "이름 짓기" → 닉네임(8자)·나이(6~13살)만 입력하면 등록. 첫 이름은 무료, 이후 변경은 30코인.
- 나이에 따라 시간 창이 조정됩니다(6~8살 ×1.15, 9~10살 ×1.0, 11~13살 ×0.9, 14~17살 ×0.8, 어른 ×0.7). 시행 수·규칙은 동일.
- 14살 이상은 재미 위주: 스테이지 1~3 바로 열림, 하루 45분, 스테이지 지도의 ⚡ 스피드 도전(시간 창 75%·코인 2배).
- 캐릭터 고르기: 포코(기본)·토토(토끼)·도토(다람쥐)·부우(부엉이) — 상점에서 코인으로 열고 선택. 달리기·점프·숙이기·표정이 모두 바뀝니다.
- 주간 점수 = 별×20 + 그 미션에서 번 코인. 랭킹은 전체/내 나이대/친구/나이대 분석, 30초마다 새로고침.
- 친구 초대: 6자리 코드 또는 `?invite=CODE` 링크. 초대받은 아이가 등록하면 둘 다 +50코인.
- 백엔드: Supabase 프로젝트 `lumo`의 `poko_players`/`poko_scores` + `poko_*` RPC 함수 (RLS로 직접 접근 차단). 스키마는 `docs/게임기획서.md` 참고.

## 재배포
`bash tools/deploy.sh "메시지"` — 서비스워커 캐시 목록 갱신 → main 푸시 → `game/`를 `gh-pages`로 발행 (GitHub Pages).

## 세션 구성 (약 20분, 하루 25분 상한)
핵심 4개(억제·작업기억·지속주의·간섭통제) + 날짜별 로테이션 3개(12개 세계 중) = 7개 미션(약 12분). 미션마다 즉각 피드백·코인·콤보, 완료 시 별 1~3개(오답에 비처벌적). 황금 별별이(희귀 보너스)와 날짜별 "오늘의 도전"으로 매일 변주.

## 스테이지 구조
세계마다 스테이지 1~10 지도. 스테이지 = 난이도 레벨. 별 2개(정확도 75%↑) 이상이면 다음 스테이지 해금, 10은 👑 보스 스테이지. 스테이지마다 새 요소가 해금됨(코인 자석 → 황금 별별이 → 새벽빛 → 미니보스 → 보호막 → 황금 시간 → 오로라·코인 비 → 어둠 → 보스전).

## 테스터 모드
보호자 리포트 → 🧪 테스터 모드: 전체 스테이지 해금 + 미션 길이 1/3. 기록은 리포트에서 제외. "오늘의 탐험"은 해금 범위 안에서 적응형으로 레벨을 고른다.

## 휴대폰 웹앱
`dist/poko-focus-pwa.zip`을 HTTPS 호스팅(Netlify Drop, GitHub Pages)에 올리면 홈 화면 설치·오프라인 실행. 자세한 방법은 `dist/배포방법.md`.

## 조작
- 반응: 스페이스 / 화면 터치 / 큰 버튼. 물약 공방은 1~4 키 또는 물약 버튼, 강물 길잡이는 ← → 키 또는 화면 좌/우 터치
- **음악**: 홈 우상단 / HUD의 🔊 버튼으로 BGM 켜기·끄기(설정 유지). 세계마다 다른 곡, 스테이지 구간(1–3/4–6/7–9/10)마다 편곡이 바뀜. 일시정지 시 볼륨 감소
- **일시정지**: HUD 오른쪽 ❚❚ 버튼 또는 Esc → 타이머·애니메이션 정지. "그만하기" → 게임 안 확인창(브라우저 confirm 미사용, 샌드박스 웹에서도 동작) → 미션 중단(해당 미션 기록은 저장되지 않음)

## 보호자 리포트
홈 → "보호자 리포트": 미션별 정확도 추세, 누락률(부주의)·오경보율(충동성)·RT 변동성(지속주의)·스트룹 간섭 효과. JSON 내보내기 지원.
